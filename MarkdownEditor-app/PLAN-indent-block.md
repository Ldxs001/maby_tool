## 语义定稿（与主人多轮分析确认）

- `<<<` ... `<<<`：缩进包围块。开闭同符号、状态翻转；**不支持嵌套**（块内 `<<<` 行 = 闭合）。
- 继承链只流**容器级缩进**（margin/padding），段内 text-indent（首行缩进/悬挂）不进链。
- curIndent 状态机（顺序扫描单变量）：
  - 空行 / 标题 / 围栏 / hr / 表格等任何其他块 → **清零**（与 olSeq 同口径）；
  - 块外顶层块更新：段落 = 首行缩进档生效处；列表 = 整项缩进后文本起点；引用 = 整体缩进处；
  - `<<<` 开（紧邻才继承；隔空行/其他块则从 0 起步）：冻结 curIndent 为块内左边界；
  - 块内：内容照常渲染、**不更新** curIndent；
  - `<<<` 闭：curIndent = 块边界 + 块内容器级子块叠加（列表/引用档）。
- fail-closed：未闭合的 `<<<` 按普通文本渲染，标记字面保留。
- 标记行渲染时整行吞掉。
- 列表、引用排版档合并：各留一个「整体缩进」（容器级），旧「首行/悬挂」两档废弃；旧配置两键取非零迁移。
