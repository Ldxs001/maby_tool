# 商店更新说明

> 每次提交微软商城时，把对应版本段落复制进「此版本中的新增功能」字段（纯文本，不带 Markdown 标记）。
> 只写用户能感知的变化，不写内部机制、文件路径与测试计数。

## v2.24.0

历史版本（仅 .smd）

· 文件面板改为两列：左列是内置文档与最近文件，右列是这份文档的历史版本
· .smd 每次保存自动留下被替换掉的上一版，右列按时间倒序列出，显示序号、保存时间、字数和标题
· 点任意一版先只读预览，确认后点「恢复到此版本」，按钮变「确认恢复？」再点一次才执行
· 恢复是交换：选中的版本变成当前内容，恢复前的内容同时变成最新一条历史，随时可以再换回来，条数不变
· 右列标题里可改「保留 N 份」，默认 30、范围 1~200，超出的自动删最旧的
· .md 右列直接写明不支持历史版本——普通 Markdown 保存是覆盖写，磁盘上永远只有当前这一份

打开文档时清理没用的图片

· 每次打开文档会清掉同名 .assets 目录里正文已经不再引用的图片和附件，状态栏说一句清掉了几个，没有可清理的就不提示
· .smd 按「当前内容 + 已保留的全部历史版本」判断：只在某条历史里用到的图片会留着，恢复到那一版不会破图
· 清理不可恢复，备着但还没写进正文的素材也会被删；要保留的素材请先写进正文或存到别处

未命名文档的自动保存

· 还没另存为过的新文档，自动保存到点会弹一次「另存为」
· 取消后本次运行不再反复弹，只在状态栏提示还没有保存路径；新建文档或另存为成功后重新计时

### English

Version history (.smd only)

· The file panel is now two columns: built-in docs and recent files on the left, version history on the right
· Every save of an .smd keeps the previous version it replaced; the right column lists versions newest first with number, save time, word count and title
· Click a version for a read-only preview, then press "Restore this version" — it turns into "Confirm restore?" and only runs on the second click
· Restoring swaps rather than overwrites: the chosen version becomes the current text and the previous current text becomes the newest history entry, so you can always switch back and the count stays the same
· Change "keep N versions" in the column header: default 30, range 1-200, oldest dropped beyond that
· For .md the right column states plainly that history is not supported — plain Markdown saves overwrite, so only the current file exists on disk

Cleanup of unused images on open

· Opening a document removes images and attachments in the matching .assets folder that the text no longer references, with a one-line count in the status bar (silent when there is nothing to remove)
· For .smd the check covers the current text plus every kept history version: images used only by a history entry are kept so restoring that version still shows them
· Cleanup cannot be undone, and spare material you have not referenced yet is removed too; write it into the text first or keep it elsewhere

Autosave for unnamed documents

· A document that has never been saved now asks once for a save location when the autosave timer fires
· If you cancel, it stops asking for the rest of the session and just notes in the status bar that there is no save location yet; a new document or a successful Save As starts the cycle again

## v2.23.3

文档信息（元数据）两种写法都认

· 兼容写法：文档开头用两条 --- 夹一段 标题／作者／日期／标签／备注，编辑器直接识别，不改你的文件格式
· 自有写法：正文只留一行 @@ meta，真正的值存进同目录的隐藏元数据文件，正文保持干净，值跟着文件走
· 元数据只在预览区显示：不打印、不导出到 Word、不进 HTML 导出
· 两种写法同时出现会给出冲突提示，两边都不显示，也不替你猜哪份为准

排版面板改版

· 改成整齐的三列网格，同排卡片等高，开关统一贴到各自卡片右侧，段间距数值不再被截断；窗口变窄自动收成两列、单列
· 面板界面补齐英文，切到 EN 不再混着中文

保存

· 手动保存、Ctrl+S、自动保存统一走同一条落盘路径
· 未命名文档开着自动保存不再反复弹「另存为」
· .smd 反复保存不再越存越大；保存失败留下的临时备份会自动清理

其他修复（此前未上架的版本一并带上）

· .smd 里替换同尺寸图片、含空格的文件名不再丢失
· 连点保存、并发保存不再互相覆盖；普通 .md 保存也改为原子写入，行尾跟随文件原样
· 子目录图片、URL 编码的图片引用不再被漏掉

内置《使用指南》新增「元数据」一章：两种写法的判据、面板怎么填、导出时怎么处理都写在里面。

### English

Document info now works two ways

· Front matter: a --- block at the very top with title / author / date / tags / note is recognised as-is, your file format stays untouched
· Built-in: a single @@ meta line in the text, the values live in a hidden metadata file next to the document
· Metadata is preview-only: never printed, not written into Word export, not rendered in HTML export
· If both styles appear, a conflict notice is shown and neither is displayed

Typeset panel rebuilt

· A tidy three-column grid with equal-height cards, switches aligned to the right edge, numbers no longer clipped; collapses to two columns and then one on narrow windows
· Full English labelling for the panel

Saving

· Manual save, Ctrl+S and autosave now share one write path
· Autosave no longer pops a Save As dialog for unnamed documents
· Repeated saves of .smd files no longer grow the package; stale temp backups are cleaned up

Other fixes carried over from unreleased builds

· Replacing an image with an identical-size one, or assets with spaces in the name, no longer get lost in .smd
· Concurrent saves no longer overwrite each other; plain .md saves are atomic and keep the file's existing line endings
· Sub-directory images and URL-encoded image references are no longer dropped

The built-in guide gains a Metadata chapter covering both styles, the panel fields and export behaviour.
