# 商店更新说明

> 提交微软商城时，把「本次更新」整段复制进「此版本中的新增功能」字段（纯文本，不带 Markdown 标记）。

## 本次更新

· 配置里多了一份图解手册：每个写法、每项设置都有一段示意动画，左边是你要写的东西，右边是它会变成什么样，一眼看懂"这么写能得到什么"。讲打印断页、页码这些光看文字想不明白的，现在能看见纸怎么翻、页码怎么数。中英文都有，面板里直接切换

· 打开程序时不再是那份长长的说明，而是一页速查：最常用的写法一张表看完，中文和英文并排，底下三条总规矩管住全部语法。查一个符号不用再翻半天

· 原来那份完整说明改名「实操手册」，还在「打开」的内置文档里，也可以从最近文件里找到。它保留可编辑、可另存，拿它改、拿它试都行。三份文档各管一段：速查看写法，手册看效果，实操手册看全部细节

· 英文界面补齐了：设置面板、快捷键一览、插入链接与插入图片、公式面板、分页预览、选中文字后弹出的快捷按钮、各处悬停提示，现在切到英文不再夹中文

### English

· Typesetting now has an illustrated handbook: every syntax and every setting comes with a short animation — what you type on the left, what you get on the right — so "what does this actually produce" is answered at a glance. Things that never made sense in prose, like page breaks and page numbering, now show the sheet moving and the numbers counting. Chinese and English, switchable inside the panel

· The program no longer opens on the long document but on a one-page cheat sheet: the most-used syntax in a single table, Chinese and English side by side, with three rules that cover everything underneath. Looking up a symbol no longer means scrolling through pages

· The full document is now called the Practice handbook and still lives under Open → Built-in documents. It stays editable and saveable — change it, experiment on it. Three documents, three jobs: the cheat sheet for syntax, the handbook for what things look like, the Practice handbook for every detail

· The English interface is now complete: settings panels, the shortcut list, insert link and insert image, the formula panel, page preview, the quick buttons that appear when you select text, and every tooltip. Switching to English no longer leaves Chinese behind

## 历史存档

## v2.44.0

· 引用块可以换样子了：在排版设置里给全篇选左侧竖线、直角框、圆角框，或者左上角与右下角各一对大引号；边框颜色和底色也能自己挑，勾「不画」就让它完全透明。不改动任何设置时，还是原来那条竖线

· 想只改某一处引用，在这段的末尾写一对花括号就行，例如 {box r w} 是红边白底的直角框。样式名、边框色、底色顺序随便写，不写的项沿用排版设置。引用里放图片时，前一个花括号归图片、后一个归引用，互不干扰

· 修复：把引用颜色设成完全透明时，原先偶尔会冒出黑色引号或残留一条蓝竖线；现在透明只影响颜色，字的缩进和留白保持原样。想去掉大引号本身，直接换一种样式即可

### English

· Quote blocks can change shape: pick a left rule, a square frame, a rounded frame, or a pair of large quotation marks in the top-left and bottom-right corners in Typesetting. Border and background colours are yours to set, and a checkbox makes either fully transparent. Leave everything alone and the original left rule stays

· To restyle just one quote, add a pair of braces at the end of that block, for example {box r w} gives a red-bordered white square frame. Style name, border colour and background colour can go in any order, and anything omitted falls back to Typesetting. With an image inside the quote, the first pair of braces belongs to the image and the second to the quote

· Fixed: setting a quote colour to fully transparent could produce dark quotation marks or leave a blue rule behind. Transparency now changes colour only, with the indent and spacing untouched. To remove the large quotation marks themselves, pick another style

## v2.43.0

· 就地断页：新增写法 @@ blank{break}，把后面的内容推到下一页，页码照常连续往下数。此前断页只能借页区或整页块，两者都会连带换掉页码体系或撑满一整页。预览里断点处显示一条虚线加「分页」小字；打印、导出 PDF 与导出 Word 才真正分页。紧跟页区或整页块时自动合并，不会凭空多出空白页；两块之间想留一张空白页，连写两个即可

· 块级字体可以定对齐：在字体名与字号之后加 l、c、r 或 j（左／居中／右／两端），整块按这个对齐排，块内覆盖排版面板的全局设定；只写对齐也行。表格与代码块不跟随，避免整张表被带歪

· 修复：文档信息的只读保护没有真正生效。作者、日期、标签这些信息设计成建档后不可改，但这层保护原先只在新建档案那一刻设置；文档从别处拷来、从旧版本升级、或是随程序安装的内置文档，档案虽然显示为只读，实际仍能被改写。现在打开这类文档会自动补上保护，档案里的值一个字都不变

### English

· Break the page where you are: the new @@ blank{break} pushes what follows onto the next page while page numbers keep running as before. Until now a break could only be borrowed from a page region or a full-page block, and both of those also replaced the numbering scheme or filled a whole page. The preview marks the spot with a dashed rule and a small "page break" tag; the break itself happens in Print, PDF export and Word export. Right before a page region or a full-page block the two merge, so no stray blank page appears; write two in a row to leave a blank page between two blocks

· Block fonts can set alignment: add l, c, r or j (left, centre, right, justified) after the font name and size and the whole block follows it, overriding the global typesetting panel inside the block; alignment on its own works too. Tables and code blocks are left alone so a whole table is never dragged sideways

· Fixed: the read-only protection on document info was not actually in force. Author, date and tags are designed to be write-once, but that protection used to be applied only at the moment a new record was created. Documents copied from elsewhere, upgraded from older versions, or shipped with the program could still have their record overwritten even though it looked read-only. Opening such a document now restores the protection automatically, with not a single stored value changed



## v2.41.0

新增：可视化公式面板、工具栏重排、链接与本地文件入口、下划线方言

· 公式不必再背 LaTeX：点「∑」开一块格子画布，选分数 / 四角标 / 括号 / 根号 / 帽线后往格子里打字，格子里还能继续嵌套（例如分数的分母里放四角标）；插入时生成标准公式并先校验，写错不会污染文档
· 工具栏右侧收成六槽：主题在「分屏▾」、导入与最近文件在「打开▾」、另存为与存为母版在「保存▾」、排版 / run / AI 在「配置▾」；预览跟随开关改为预览栏横栏最左边的勾选框
· 格式区六组按钮各带下拉：标题级数、斜体 / 删除线 / 下划线 / 上下标 / 填空线、引用嵌套、有序与任务列表、表格列宽与题注，一键插入
· 「链接」主按钮改为开窗分开填「链接文字」与「链接地址」；下拉新增「插入图片…」（网络地址或本机图片）、「插入本地文件…」与「取消链接」
· 插入本地文件与「复制文件后粘贴」走同一条流程：文件进文档资产目录、渲染区出现「打开」按钮、随自包含文档一起打包，两种放进来方式的结果完全一致
· 新增下划线 `++文字++`、填空线 `++{0 x 9}++` 与填空格 `++{□ x 5}++`；B▾ 里有对应菜单项
· 「配置」按钮打开关于面板：三个标识、当前版本号与快捷键列表；快捷键可改（撞键会拒绝），新增 Ctrl+B 加粗、Ctrl+I 斜体，撤销键保持系统原生

修复与精简

· 表格 / 链接 / 公式等弹窗插入后不再跳回文首，预览滚动位置保持；六个小三角样式统一，下拉不再跑到窗口左下角
· 点「选择本地图片…」只弹一次文件选择框；导出 Word 时下划线里的粗体 / 斜体不再丢线，四角标的前置角标改用 Word 正规结构
· 移除列表下拉里两项无效的「缩进 / 取消缩进」：排版缩进用「排版」面板，整体缩进用 `<<<` 包围块
· 内置使用指南已同步到本版本

### English

New: visual equation canvas, reorganised toolbar, link and local-file entries, underline dialect

· Equations no longer require memorising LaTeX: press ∑ for a grid canvas, pick a fraction, four-corner scripts, brackets, a root or an accent, then type into the slots. Slots nest freely (a four-corner script inside a denominator, for example). Insertion writes a standard formula and validates it first, so a mistake never reaches the document
· The right-hand toolbar is now six slots: the theme under Split ▾, import and recent files under Open ▾, Save as and Save as template under Save ▾, typesetting / run / AI under Config ▾. Scroll follow is now a checkbox at the left of the preview bar
· Six format groups each have a dropdown: heading levels, italic / strikethrough / underline / super-subscript / ruled blanks, quote nesting, ordered and task lists, table width and caption commands
· The Link button opens a dialog with separate text and address fields. Its dropdown adds Insert image… (network URL or local file), Insert local file… and Remove link
· Inserting a local file uses exactly the same path as pasting a copied file: the file is copied into the document's asset folder, the preview shows an Open button, and self-contained documents carry it along. Only the way of choosing the file differs; everything afterwards is identical
· New underline `++text++`, ruled blanks `++{0 x 9}++` and boxes `++{□ x 5}++`, also available in the B ▾ menu
· The Config button opens About: three logos, the current version and a shortcut list. Keys can be rebound (conflicts are refused); Ctrl+B and Ctrl+I are new, undo stays native

Fixes and simplifications

· Inserting from a dialog (table, link, equation) no longer jumps the editor back to the top, and preview scroll is preserved. All six carets share one style and dropdowns no longer appear in the bottom-left corner
· Choosing a local image opens exactly one file picker; bold and italic text inside an underline keeps its line in Word export, and prescripts use Word's native structure
· Removed two ineffective indent entries from the list dropdown: use the Typesetting panel for paragraph indent and `<<<` blocks for whole-block indent
· The built-in user guide is updated to this version

## v2.24.0

历史版本（仅 .smd）

· 文件面板改为两列：左列是内置文档与最近文件，右列是这份文档的历史版本
· .smd 每次保存自动留下被替换掉的上一版，右列按时间倒序列出，显示序号、保存时间、字数和标题
· 点任意一版先只读预览，确认后点「恢复到此版本」，按钮变「确认恢复？」再点一次才执行
· 恢复是交换：选中的版本变成当前内容，恢复前的内容同时变成最新一条历史，随时可以再换回来，条数不变
· 右列标题里可改「保留 N 份」，默认 30、范围 1~200，超出的自动删最旧的
· .md 右列直接写明不支持历史版本——普通 Markdown 保存是覆盖写，磁盘上永远只有当前这一份

打开文档时清理没用的图片

· 每次打开文档会清掉同名 .assets 目录里正文已经不再引用的图片和附件，状态栏说一句清掉了几个，没有可清理的就不提示
· .smd 按「当前内容 + 已保留的全部历史版本」判断：只在某条历史里用到的图片会留着，恢复到那一版不会破图
· 清理不可恢复，备着但还没写进正文的素材也会被删；要保留的素材请先写进正文或存到别处

未命名文档的自动保存

· 还没另存为过的新文档，自动保存到点会弹一次「另存为」
· 取消后本次运行不再反复弹，只在状态栏提示还没有保存路径；新建文档或另存为成功后重新计时

### English

Version history (.smd only)

· The file panel is now two columns: built-in docs and recent files on the left, version history on the right
· Every save of an .smd keeps the previous version it replaced; the right column lists versions newest first with number, save time, word count and title
· Click a version for a read-only preview, then press "Restore this version" — it turns into "Confirm restore?" and only runs on the second click
· Restoring swaps rather than overwrites: the chosen version becomes the current text and the previous current text becomes the newest history entry, so you can always switch back and the count stays the same
· Change "keep N versions" in the column header: default 30, range 1-200, oldest dropped beyond that
· For .md the right column states plainly that history is not supported — plain Markdown saves overwrite, so only the current file exists on disk

Cleanup of unused images on open

· Opening a document removes images and attachments in the matching .assets folder that the text no longer references, with a one-line count in the status bar (silent when there is nothing to remove)
· For .smd the check covers the current text plus every kept history version: images used only by a history entry are kept so restoring that version still shows them
· Cleanup cannot be undone, and spare material you have not referenced yet is removed too; write it into the text first or keep it elsewhere

Autosave for unnamed documents

· A document that has never been saved now asks once for a save location when the autosave timer fires
· If you cancel, it stops asking for the rest of the session and just notes in the status bar that there is no save location yet; a new document or a successful Save As starts the cycle again

## v2.23.3

文档信息（元数据）两种写法都认

· 兼容写法：文档开头用两条 --- 夹一段 标题／作者／日期／标签／备注，编辑器直接识别，不改你的文件格式
· 自有写法：正文只留一行 @@ meta，真正的值存进同目录的隐藏元数据文件，正文保持干净，值跟着文件走
· 元数据只在预览区显示：不打印、不导出到 Word、不进 HTML 导出
· 两种写法同时出现会给出冲突提示，两边都不显示，也不替你猜哪份为准

排版面板改版

· 改成整齐的三列网格，同排卡片等高，开关统一贴到各自卡片右侧，段间距数值不再被截断；窗口变窄自动收成两列、单列
· 面板界面补齐英文，切到 EN 不再混着中文

保存

· 手动保存、Ctrl+S、自动保存统一走同一条落盘路径
· 未命名文档开着自动保存不再反复弹「另存为」
· .smd 反复保存不再越存越大；保存失败留下的临时备份会自动清理

其他修复（此前未上架的版本一并带上）

· .smd 里替换同尺寸图片、含空格的文件名不再丢失
· 连点保存、并发保存不再互相覆盖；普通 .md 保存也改为原子写入，行尾跟随文件原样
· 子目录图片、URL 编码的图片引用不再被漏掉

内置《使用指南》新增「元数据」一章：两种写法的判据、面板怎么填、导出时怎么处理都写在里面。

### English

Document info now works two ways

· Front matter: a --- block at the very top with title / author / date / tags / note is recognised as-is, your file format stays untouched
· Built-in: a single @@ meta line in the text, the values live in a hidden metadata file next to the document
· Metadata is preview-only: never printed, not written into Word export, not rendered in HTML export
· If both styles appear, a conflict notice is shown and neither is displayed

Typeset panel rebuilt

· A tidy three-column grid with equal-height cards, switches aligned to the right edge, numbers no longer clipped; collapses to two columns and then one on narrow windows
· Full English labelling for the panel

Saving

· Manual save, Ctrl+S and autosave now share one write path
· Autosave no longer pops a Save As dialog for unnamed documents
· Repeated saves of .smd files no longer grow the package; stale temp backups are cleaned up

Other fixes carried over from unreleased builds

· Replacing an image with an identical-size one, or assets with spaces in the name, no longer get lost in .smd
· Concurrent saves no longer overwrite each other; plain .md saves are atomic and keep the file's existing line endings
· Sub-directory images and URL-encoded image references are no longer dropped

The built-in guide gains a Metadata chapter covering both styles, the panel fields and export behaviour.
