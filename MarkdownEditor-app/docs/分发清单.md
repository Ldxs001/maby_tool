## 一、启动链（缺任何一个 = 双击 .md 打不开，直接失败）

| 文件/目录 | 身份 | 缺失后果 |
|---|---|---|
| `python/` | 便携解释器（embeddable Python 3.11 + PIL 13.0.0 + 依赖） | md_launch/md_app 找不到 `python/pythonw.exe`，完全无法启动 |
| `md_launch.pyw` | 入口（.md 右键/双击关联指向它） | 右键菜单点了没反应 |
| `_md_run.py` | 服务启动 shim（v1.11.0，走 pyc 提速） | md_launch/md_app 的 Popen 硬指向它，服务起不来，wait_version 超时后连兜底浏览器都开不了页面 |
| `md_server.py` | 后端主服务（2251 行，MD_SERVER_VERSION=52） | 没有 API、没有页面，一切归零 |
| `markdown-editor.html` | 前端单文件（2689 行） | 页面 404 |
| `md-editor.ico` | 全局图标 | splash 图标降级为色块、快捷方式/install 编译 EXE 时图标缺失 |

> **⚠️ `python/` 必须整目录分发，禁止只挑 `.py`**：内含 pythonnet 原生桥接层
> `python/Lib/site-packages/pythonnet/runtime/Python.Runtime.dll`（+ `.deps.json` + `.xml`）
> ——pywebview 挂载**系统 WebView2 控件**的 .NET 互操作必需件，缺失则 `webview.start()` 直接崩、
> 内嵌窗口静默无窗口（`launch_embedded` 进程拉起即返回 True，不会回退浏览器）。
> v1.11.1 曾因 `.gitignore` 的 `runtime/` 未锚定误伤此目录，三个文件从未入库 → Releases 下载后无法运行；
> 已修复：`.gitignore` 改 `/runtime/` 锚定 + 三文件补交入库。分发前自验**必须断言 DLL 存在**（`_test_dist_verify.py`）。

### 环境前提（非文件，装机时需知）

- Windows 10/11（ctypes/Win32、WebView2；浏览器模式需默认浏览器可用）
- install.cmd 编译需 .NET Framework 4 的 csc.exe（系统标配，缺失时直接用预编译 exe）
- 端口 18766（编辑器服务）、8767（RAG，可选功能）
- 四个 `.cmd` 脚本（install/uninstall/md_stop/desktop-shortcut）调用系统自带的 **Windows PowerShell**（`System32\WindowsPowerShell\v1.0\powershell.exe`，Win10/11 内置组件，无法被"可选功能"移除）。已统一用**绝对路径**调用、**不依赖用户 PATH**——PATH 残缺的机器也能正常安装/卸载/停服务/建快捷方式。修复：此前裸用 `powershell` 在 PATH 未含该子目录的机器上报"不是可运行命令"。
