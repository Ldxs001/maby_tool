# low runner 返回值契约（方案）

> 状态：表格与换行**已实施**（v2.7.0）；图片落点（第三节 G3/G4/G5）**已并入《low runner 实施方案-外部引用与结果图片》，本节仅作历史留档**
> 定位：把"run 返回什么形状、前端认什么"写成明面规矩。框架不替 run 作者决定内容，
> 只保证"写对了就一定显示对"。
> 与《low runner 外部文件引用-方案》共用同一条协议改造（请求体补 `mdPath`）。

## 一、契约（用户视角，就是规矩本身）

### 1. 返回值只有三种形状

| run 返回 | 前端怎么认 | 显示成 |
|---|---|---|
| `str` 单行 | 行内 markdown | 一段文字 |
| `str` 多行（含 `\n`） | 行内 markdown + 保留换行 | 多行文字，不再挤成一行 |
| `str` 里含表格块 | 表格 | 真表格 |
| `list` | 逐元素 `str()`，逗号连接 | 一行文字（global 执行点按标记逐个替换） |

`[[]]` 直接返回就是 Python 的列表形状（`['a', 'b'],['c', 'd']`）。要好看的排版，自己拼成字符串——这是 run 作者的事。

### 2. 表格：写对了就是真表格

判定只有一条，与正文表格完全同一口径：

- 某一行含 `|`；
- **紧跟的下一行是分隔行**（只含 `|` `-` `:` 和空格，且含 `-`）。

满足 → 这一块渲染成 `<table>`；不满足 → 一个字符都不动，原样当文字（fail-closed，不猜）。

```
| 项目 | 一月 | 二月 |
| --- | ---: | :---: |
| 收入 | 100 | 120 |
```

- 对齐：`---` 左对齐、`---:` 右对齐、`:---:` 居中（GFM 原样）。
- 单元格内的竖线写 `\|`。
- 表格块之间用空行隔开，可返回多张表。
- 表格前后的普通行按文字渲染，换行保留。
- **不支持**：单元格内换行、跨行跨列合并。这是 GFM 的边界，不是实现偷懒。

### 3. 图片：run 自己写文件，返回相对引用

- run 写文件的基准目录 = **本文档的资产目录**（`.md` 是 `<文档名>.assets/`，`.smd` 是包内 `assets/`）。由框架设好，run **不需要知道它叫什么**。
- 推荐写法：`save('x.png')` → 返回 `![](x.png)`。
- 写成 `save('assets/x.png')` 也能落，但会在资产目录里多套一层 `assets/`，不推荐。
- 文件名重名自行避免（框架不替你改名）。
- 返回的 `![](x.png)` 必须在预览区显示、在 docx/html 导出里带上、在 `.smd` 里进包。

### 4. 结果里不生成数据点

执行点显示的文本里出现 `@@ MDE…` 或 `'''标记`，**只当普通文字**。这条不是限制作者，是防"一个 run 的输出悄悄改另一个 run 的输入"。

## 二、现状缺口（全部实测，不是推断）

| # | 缺口 | 证据 |
|---|---|---|
| G1 | 表格不渲染 | run 返回 GFM 表格 → 预览 `table` 元素 **0 个**，显示为一行竖线文字 |
| G2 | 换行被折叠 | run 返回三行文本 → 容器高度 **20px**（单行） |
| G3 | 相对路径不落文档 | `save('assets/x.png')` → 实际落在 `runtime/run_cache/assets/x.png`，文档目录为空 |
| G4 | 落错还看不出来 | 因为改写函数也在 `run_cache` 里找，预览**显示正常**，换机器/导出才断 |
| G5 | 资产目录的相对引用 404 | 返回 `![](<名>.assets/x.png)` → 浏览器请求 `/ <名>.assets/x.png` → 404 |
| G6 | 结果能反向生成数据点 | run 返回 `@@ MDE_乙{注入 == 7}` → 预览多出一个数据点（`insideRun=true`），进「乙」池 |

## 四、验收

1. 返回上表那张 GFM 表 → 预览是 `<table>`，三列对齐正确，导出 docx 是真 `w:tbl`。
2. 返回三行文本 → 三行显示（容器高度约为单行的 3 倍）。
3. 不写分隔行的一组竖线行 → 原样文字，不进表格分支。
4. `save('x.png')` + `![](...)` → 文件出现在文档资产目录；预览显示；导出 docx 带图；存 `.smd` 后图在包内。
5. 返回里写 `@@ MDE_甲{x == 1}` → 预览只显示这行字，不产生数据点、不进池。
6. 现有 5 个 run（`tablecalc` / `stats` / `wordcount` / `mergecontent` / `auto_cite`）结果与改动前逐字节一致。

## 五、边界（明确不做）

- 不做单元格内换行、跨行跨列合并。
- 不做"猜表格"：没有分隔行就不是表格。
- 不改资产目录命名（`.md` 仍是 `<名>.assets/`）。
- 不允许 run 返回值反向生成数据点或标记。
